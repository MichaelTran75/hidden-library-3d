# Hidden Library 3D

Audiobook library as a 3D reading room (three.js). Live: https://michaeltran75.github.io/hidden-library-3d/

- Build: `python3 src/build.py src/hidden-library.base.html --pages .`
- Source: `src/` (modules in `src/lib3d`, map in `src/ARCHITECTURE.md`).
- Screens ≤ 768 px or no WebGL 2: card layout.
